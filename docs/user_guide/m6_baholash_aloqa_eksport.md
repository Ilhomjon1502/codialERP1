# Baholash, ota-onalar bilan aloqa, Excel eksport (M6)

> «Talaba vazifalari», «Baholash bo'limi» (ustoz → talaba) va «50% chegirmalar» bo'limlari buyurtmachi qarori bilan olib tashlangan (2026-10-13).

## Baholash (talaba → ustoz)

Menyu → **Baholash (ustozni)** → **Yangi baholash**: talaba → ustoz o'zi aniqlanadi (talabaning guruhidan) → 5 mezon, har biri 0–10 → izoh.
Talabalar tizimga kirmaydi — javoblarni administrator kiritadi. Tepada har ustozning o'rtacha bali (50 dan). Oy bo'yicha filtr bor.

Mezonlar: 1) mavzuni sodda tushuntira oladimi; 2) dars qiziqmi, qiziq metodlar; 3) adolatli, teng e'tibor; 4) kerak vaqtda yordam; 5) tavsiya berib ruhlantiradimi.

## Ota-onalar bilan aloqa

Chapda daraxt: **Barchasi → kurs → guruh** (sonlari bilan), bosilgan tugun bo'yicha jadval filtrlanadi.
**Yangi yozuv:** kurs → guruh → talaba → telefonlar o'zi chiqadi → sana → izoh. Jadvalda 📞 qo'ng'iroq va SMS havolalari (talabaning ikkala telefoni va vasiy).
**✎ Tahrirlash** — faqat sana va izoh (talaba o'zgarmaydi); tahrirlangan izoh ostida «✎ kim · qachon». **🗑 O'chirish** — Admin va Bosh menejer.
Ustoz faqat o'z guruhlari yozuvlarini ko'radi.

## Shartnoma yuklash (Excel)

Menyu → **Shartnoma yuklash**: kurs → guruhlar (bir nechtasini tanlash mumkin) → **Excel'ga yuklash** — `.xlsx` fayl:
talaba, telefonlar, vasiy, kurs, guruh, turi, sanalar, to'xtatish sababi, status, hisoblangan, to'langan, chegirma, balans.

**Shartnomalar** sahifasidagi **Excel** tugmasi ham endi `.xlsx` beradi — joriy tab va filtrlar bo'yicha. Har yuklash Audit tarixiga yoziladi.
