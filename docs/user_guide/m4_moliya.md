# Moliya (M4)

## To'lovlar

Menyu → **To'lovlar**: oy → sana bo'yicha, kun va oy jami summalari bilan. Qidiruv: talaba, shartnoma yoki chek raqami.

**To'lov qabul qilish** (shartnoma sahifasidan yoki qarzdorlar ro'yxatidan ham):

1. Shartnoma → joriy balans ko'rinadi.
2. Summa → to'lov shakli (Naqd / Karta / Bank).
   - **Naqd** — siz mas'ul bo'lgan g'azna (bitta bo'lsa o'zi tanlanadi).
   - **Karta / Bank** — filialning naqdsiz g'aznasi (Sozlamalar → Filiallar). Naqdsiz to'lov **tasdiqlanmaguncha g'azna balansiga qo'shilmaydi**.
3. Chegirma (ixtiyoriy): turi va summasi. Summa chegirma turining eng ko'p miqdoridan oshmaydi. Chegirma tasdiqlashga ketadi.
4. Sana: hisobchilar — faqat bugun; Admin va Bosh menejer o'tgan sanani ham kiritadi.

Saqlangach **chek (PDF)** ochiladi. Chekni istalgan payt «Chek» tugmasi bilan qayta ochish mumkin — u doim joriy ma'lumot bilan chiqadi. Tasdiqlanmagan to'lov chekini faqat Admin, Bosh menejer va Filial menejeri ko'radi.

Kim qabul qiladi: Admin, Bosh menejer, Administrator+Hisobchi, Hisobchi. Administrator va ustozlar faqat ko'radi (yoki umuman ko'rmaydi).

Tahrirlash va o'chirish: hisobchilar — faqat bugungi to'lov; tasdiqlangan to'lov yoki chegirmani faqat Admin va Bosh menejer o'zgartiradi. O'chirilgan to'lov bazada qoladi (Audit tarixida ko'rinadi), g'azna balansidan chiqariladi.

Talaba qarzi: to'lov va chegirma kiritilgan zahoti balansdan ayiriladi.

## Tasdiqlashlar

Menyu → **Tasdiqlashlar** (yuqoridagi qo'ng'iroqcha — sizning tasdig'ingizni kutayotganlar soni):

| Nima | Kim tasdiqlaydi |
|---|---|
| Chegirma | Admin — istalgan vaqt; Bosh menejer — yaratilganidan keyin 30 kun ichida |
| Naqdsiz to'lov | Admin; Bosh menejer — 360 kun, Filial menejeri — 7 kun ichida |
| O'tkazma | Qabul qiluvchi g'azna mas'uli yoki Admin |
| Qoldirilgan dars | Bosh menejer, Filial menejeri, administratorlar |
| Oydagi dars soni | Admin, Bosh menejer, Filial menejeri |

## G'aznalar

Menyu → **G'aznalar**: har g'aznaning joriy balansi, pul turlari bo'yicha (naqd, karta, bank) va tasdiqlanmagan summalar. G'aznani bosing — barcha pul harakatlari (to'lov, xarajat, o'tkazma, ayirboshlash, kreditor) oy bo'yicha.

Balans = boshlang'ich qoldiq + barcha tasdiqlangan harakatlar. G'azna qo'shish va mas'ullar — Sozlamalar → G'aznalar.

## Ichki pul oqimi (o'tkazmalar)

G'aznalar orasida **naqd** pul o'tkazish. Yuboruvchi — siz mas'ul bo'lgan g'azna; summa g'azna qoldig'idan oshmaydi. Qabul qiluvchi g'azna mas'uli «Qabul qildim» ni bosmaguncha pul ikkala g'aznada ham hisobga olinmaydi. Summa va g'aznalarni keyin faqat Admin o'zgartiradi.

## Pul ayirboshlash (Admin, Bosh menejer)

Masalan naqdni kartaga: berilgan summa → olingan summa (berilgandan katta bo'lmaydi). Farq — yo'qotish.

## Xarajatlar

**Xarajat qo'shish:** sana → kategoriya (faqat rolingizga ruxsat berilganlari) → nomi (oldingi nomlar taklif qilinadi) → soni × narxi → to'lov shakli → g'azna. Xarajat g'azna qoldig'idan oshmaydi (Admin va Bosh menejerdan tashqari). Hisob davri sanadan olinadi; boshqa oyni faqat Admin va Bosh menejer qo'yadi.

Tablar: «Sana bo'yicha» va «Oy → kategoriya» (har oy kategoriyalar jami bilan).

## Tashqi pul oqimi (kreditorlar — Admin, Bosh menejer)

Kreditor kartochkasi: joriy haqqi = boshlang'ich haqqi − barcha amallar. **Amal kiritish:** «−» — qarz olish (g'aznaga pul kiradi), «+» — qarz qaytarish (g'aznadan chiqadi). Izohlar ham yoziladi.

## Lidlar → To'lov qilganlar

Talabasi to'lov qilgan lidlar: birinchi to'lov sanasi va to'lovlar jami.
